# Naming

## Rule

Names should feel as if they have histories.

The setting should use the *logic* of real place naming rather than random fantasy phonetics.

Useful naming sources include:
- geography: river mouth, red hill, narrow pass, clear water;
- settlement function: market, fort, port, bridge, shrine;
- founder or lineage;
- older ethnic or linguistic groups;
- industry or resource;
- aspirational names;
- religious or philosophical associations;
- conquest and renaming;
- translation layers where an old name survives in a newer language.

## Real-world pattern pools already discussed

The project has explicitly looked at:
- American descriptive, occupational, founder, Indigenous, immigrant, and aspirational place names;
- Middle Eastern names tied to geography, settlement, religion, rulers, and function;
- Scandinavian compound names tied to terrain, farms, harbors, markets, and people;
- Chinese names built from geographic position, symbolic concepts, administrative function, and older historical references.

The lesson is **not** to copy the sound of these languages indiscriminately. It is to give each region a coherent history of naming.

## Regional direction

Exact naming languages remain open, but a useful model is:

- **Ironcrest:** older upland/river names beneath later mining, fort, family, and guild names.
- **Northwind:** coastal geography, bays, islands, currents, lineages, seasonal sites.
- **Greenvale:** rivers, soils, old settlements, family lands, markets, former estates.
- **Highridge:** route names, passes, wells, caravan families, old toll sites, translated names from multiple languages.
- **Deepwood:** waterways, groves, species, older peoples, landmarks that may not be obvious to outsiders.
- **Sunplains:** old city-state names, founders, civic ideals, waterworks, forts, ports, estates.
- **Port:** layers upon layers — indigenous/old geographic name, official charter name, district nicknames, immigrant neighborhood names, merchant terminology.

## Border names

Border towns are especially likely to have:
- two accepted names;
- one name translated differently by each side;
- a hybrid name;
- an old political name nobody uses officially;
- family names crossing linguistic boundaries.

## Personal names

Do not assign one real-world ethnic naming system wholesale to a region.

Instead develop:
- sound patterns;
- common roots;
- patronymic/matronymic/family systems;
- class differences;
- marriage practices;
- regional spelling variation;
- religious names;
- older names revived for political reasons.

Several previously proposed character names are retained as **provisional** until this system is finalized.
