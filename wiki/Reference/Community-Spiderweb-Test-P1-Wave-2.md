## Promotion standard

For each community, test:

~~~text
livelihood
→ household
→ law / institution
→ food / material life
→ architecture
→ social status
→ cultural transmission
→ story pressure
→ neighboring community
~~~

Then ask whether the community still works if:

- the protagonist never visits;
- the myth is removed;
- the current crisis ends.

# 1. SH-3 — specialized craft town

## Spiderweb

~~~text
specialized production cluster
→ workshop / apprentice / supplier households
→ guild + inspection + merchant relationships
→ ordinary Stone Hills market food differentiated by status
→ workshops / storage / fire-management built form
→ reputation hierarchy among trades / makers
→ objects + apprentices + technical vocabulary travel outward
→ guild centralization / strategic demand disrupt local chain
→ SH-1 / High Roads / Port supply and market links
~~~

## Failure test A — "everyone makes one thing"

**PASS.**

The profile explicitly requires:

- several production stages;
- merchants;
- suppliers;
- unrelated services;
- independent households.

Its cultural distinctiveness comes from:

> interdependence among specialists,

not a one-resource costume.

## Failure test B — hereditary-craft essentialism

**PASS with caution.**

The historical inspiration includes inherited craft traditions, but the 10Kings profile does **not** require blood inheritance.

Entry can occur through:

- apprenticeship;
- migration;
- workshop employment.

Old family reputation may matter without controlling membership.

## Failure test C — isolated traditional town

**PASS.**

The craft cluster depends on:

- imported materials;
- merchants;
- outside demand;
- apprenticeship mobility.

It is economically outward-facing.

## Weak link

### Exact craft

Still unresolved.

This is acceptable at **community-type** level but blocks a fully specific named town because:

- fire / water / waste;
- architecture;
- supply chains;
- class structure

depend partly on what is made.

## Disposition

**P2-READY AS COMMUNITY TYPE.**

Do not promote a named craft town until one product cluster is selected.

# 2. LR-2 — estate / tenant district

## Spiderweb

~~~text
estate land / storage / capital
→ tenant + wage + agent households
→ leases / crop shares / advances / estate records
→ different household food access despite regional abundance
→ tenant farms + estate storage / offices / labor housing
→ secure / precarious tenancy hierarchy
→ migrant / harvest labor carries culture outward
→ abundance / debt crisis increases consolidation
→ LR-1 cooperatives + river markets + Port / Stone Hills labor markets
~~~

## Failure test A — estate becomes sovereign state

**PASS.**

The profile preserves a clean distinction:

LR-A:
- criminal law;
- diplomacy;
- taxation;
- military authority;
- higher courts.

Estate:
- lease;
- credit;
- storage;
- employment;
- local roads / facilities.

Daily power can be intense without sovereignty.

## Failure test B — landlord = simple villain

**PASS.**

Estate systems can provide:

- credit;
- seed;
- storage;
- infrastructure.

Those services can be:

- useful;
- coercive;
- both.

A tenant may rationally fear losing estate support even while wanting reform.

## Failure test C — all tenant households identical

**PASS.**

The profile distinguishes:

- secure tenant;
- precarious tenant;
- wage laborer;
- large tenant;
- agent / employee.

Contract differences can produce different household strategies.

## Weak link

### Estate variation

One LR-2 profile is still too broad to become:

> how Low Rivers estates work.

Need at least two estate variants later:

- commercially aggressive / debt-heavy;
- older paternal / reciprocal estate or other contrasting form.

Without contrast, the profile could become regional default.

## Disposition

**P2-READY AS ONE VALID ESTATE-DISTRICT TYPE.**

Explicitly not the universal Low Rivers estate model.

# 3. OC-3 — coastal merchant city

## Spiderweb

~~~text
maritime trade + sovereign city
→ merchant / harbor / clerk / labor households
→ civic harbor + merchant + legal + religious institutions
→ coastal / imported food transformed into local cuisine
→ warehouse / shop / residence / civic layers
→ old civic family / merchant / labor / diaspora status competition
→ legal / food / style / merchant networks travel outward
→ OC-U / OC-D cooperation creates balance-of-power anxiety
→ Port + Old Cities hinterland + maritime markets
~~~

## Failure test A — "Port but warmer"

**PASS strongly.**

Port's core political condition:

> neutral / constrained / multimodal / externally entangled.

OC-3's:

> sovereign city-state / maritime merchant power.

Therefore the same cosmopolitan mechanism produces different politics.

### Port asks

Who has the right to govern an indispensable neutral hub?

### OC-3 asks

How does a sovereign trading city preserve autonomy / leverage among rivals?

That is enough structural distinction.

## Failure test B — cosmopolitan collage

**PASS.**

The profile requires imported forms to become:

- local food;
- local architecture;
- local family traditions;
- local speech.

A several-generation merchant family is not perpetually "foreign."

## Failure test C — merchant city = merchant elite only

**PASS.**

Harbor labor / crafts / clerks / provisioning remain visible.

## Weak link

### Hinterland relation

OC-3's coastal / urban identity is strong, but its relation to:

- nearby farms;
- water;
- food hinterland;
- rural clients

needs a later site-specific pass.

That is required before named-city promotion.

## Disposition

**P2-READY AS COASTAL-MERCHANT-CITY TYPE.**

P1 as a specific OC-C city until hinterland / site history is locked.

# 4. HR-1 — central switching / arbitration city

## Spiderweb

~~~text
route convergence / mode & carrier switching
→ permanent resident + boarder + merchant / clerk households
→ arbitration / weighing / interpreter / storage institutions
→ local / traveler / elite food systems
→ caravan yards + animal market + clerk / lodging districts
→ multilingual brokerage and occupational status hierarchies
→ carrier-specific cultural diffusion
→ route disruption produces backlog / rumor / arbitration overload
→ HR-N / HR-W / Port / Low Rivers / carriers
~~~

## Failure test A — generic Silk Road city

**PASS, but only because the political system is specific.**

The city is not important because:

> caravans pass through.

It is important because 10Kings already requires:

- multiple sovereign / local route jurisdictions;
- overlapping corridor compacts;
- no High Roads central state;
- recurring arbitration.

HR-C solves a specific local problem:

> **how do people make incompatible route systems interoperable without creating one sovereign authority?**

That anchors the city beyond aesthetic Silk Road borrowing.

## Failure test B — secretly High Roads capital

**PASS if one rule is enforced.**

HR-C must never gain authority merely because:

- records;
- meetings;
- experts

are concentrated there.

It may host:

- delegations;
- arbitration;
- services.

It cannot issue ordinary law to HR-N / HR-W.

This should remain an explicit safeguard.

## Failure test C — duplicate Port

**PASS.**

HR-C is less about neutrality / shipping / continent-wide finance and more about:

- land routes;
- animals;
- contracts;
- jurisdiction translation.

## Weak link

### Local non-route economy

The city still risks feeling as though every resident serves travelers.

Need later ordinary-city layer:

- food production / nearby agriculture;
- crafts for locals;
- children / elderly;
- neighborhoods with little direct caravan work.

## Disposition

**P2-READY AS SWITCHING-CITY TYPE, WITH SAFEGUARD.**

Do not promote HR-C as cultural/political capital.

# 5. HR-3 — northern high-route settlement

## Spiderweb

~~~text
highland agriculture + livestock + route traffic
→ partly mobile / partly resident households
→ pasture / water / storage / route institutions
→ hardy local food + market imports
→ storage-heavy / animal-support / weather-adapted buildings
→ status divided among herding / farming / route-service competence
→ route / weather knowledge moves through NC-HR corridor
→ closure / convoy pressure changes lodging / pasture / animal prices
→ M-2 pastoralists + HR-N + NC-R
~~~

## Failure test A — duplicate pastoral network M-2

**PASS.**

M-2 is:

> a mobile network defined by seasonal herd movement.

HR-3 is:

> a permanent settlement that contains mobile and nonmobile households and services that movement.

A resident may:

- farm;
- repair;
- teach;
- trade;
- host;
- manage water

without ever joining the high pasture movement.

## Failure test B — "mountain people are isolated"

**PASS.**

The settlement sits on a consequential route.

Winter isolation and heavy transit can both be true at different times.

## Failure test C — mountain culture reduced to hardship

**PASS.**

The profile includes:

- market access;
- route service;
- agriculture;
- mobility;
- education tensions;
- politics.

## Weak link

### Exact site ecology

Need future map decision for:

- elevation;
- crop ceiling;
- snow;
- water;
- road geometry.

But the social type survives multiple site solutions.

## Disposition

**P2-READY AS COMMUNITY TYPE.**

# 7. New E/I candidates

## E/I A — production knowledge behaves like infrastructure

SH-3 suggests:

> **a concentration of interdependent skill can function like infrastructure.**

Destroying:

- one bridge

and losing:

- one critical specialist stage

can both disrupt a supply chain.

This may matter during war / guild centralization.

## E/I B — household form is partly political economy

LR-2 reinforces a wider pattern already present in:

- apprenticeship;
- boarding;
- mobile households;
- Port.

Household composition is not merely cultural tradition.

It can be produced by:

- tenancy;
- labor;
- migration;
- risk;
- property.

This should become a general worldbuilding rule.

## E/I C — cosmopolitanism has multiple institutional forms

Port, OC-3, and HR-C prove that:

> **cultural mixture should be derived from the kind of network a place sits inside.**

Port mixture:
- neutral multimodal exchange.

OC-3 mixture:
- sovereign maritime commerce.

HR-C mixture:
- overland interoperability.

This is a strong anti-flattening rule.

## E/I D — permanent settlement can be infrastructure for mobility

HR-3 shows:

> mobile systems often require deeply rooted places.

Winter bases, roadheads, markets, repair sites, schools, burial places, storage and kin centers make mobility possible.

This should inform all later mobile-worldbuilding.

Promote only those structural findings to owner pages.

Then the community matrix should move away from adding more same-region examples and toward the two layers that are still structurally thin:

1. **contact-zone communities**
   - SH ↔ LR;
   - LW ↔ HR;
   - LR ↔ OC.

2. **Port diaspora / second-generation communities**
   - North Coast-descended;
   - High Roads merchant / clerk;
   - Low Rivers labor / food-market;
   - Stone Hills skilled-worker.

These are now more valuable than a fourth self-contained regional community because they test whether cultural bleed actually works.
