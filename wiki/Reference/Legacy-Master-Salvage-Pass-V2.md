# Legacy Master Salvage Pass — V2

## Status

**Active source-level reconciliation pass — 2026-09-24.**

This pass exists because the first legacy reconciliation was primarily **structural**.

That first pass successfully prevented obsolete material from overriding the rebuilt world, but later recovery work showed a weakness:

> useful middle-layer material could remain buried even when a whole volume was labeled RECONCILED.

Recovered examples already include:

- guild branch autonomy / splinter politics;
- stakeholder groups that benefit from crises other people suffer;
- people who oppose both a problem and its proposed solution;
- Three Moons / Port information aggregation;
- current-event faction reactions.

The V2 pass therefore treats the legacy archive as a **quarry that must be deliberately mined**, not simply fenced off.

---

# 1. Review levels

## SCREENED V2

The source has been included in the source-level V2 inventory and inspected for:

- causal mechanisms;
- institutions;
- internal factions;
- ordinary-life detail;
- logistics / routes;
- historical residue;
- story mechanics;
- current-event consequences.

SCREENED does **not** mean every sentence was promoted.

## DEEP REVIEWED V2

The source received a focused semantic read because it showed high salvage value.

Its useful material must be dispositioned as one or more of:

- **PROMOTED** — integrated into a current owner;
- **MECHANISM** — useful structural rule retained in active Reference;
- **SEED** — compatible specific idea preserved for later local testing;
- **DUPLICATE** — already represented adequately by current owners;
- **CONFLICT** — useful but incompatible with current canon; preserve provenance;
- **REJECTED** — depends on a discarded premise / unsupported technology / caricature;
- **COLD** — primarily historical packaging or low-value brainstorm.

## SOURCE-LEVEL COMPLETION

A thematic volume is V2-complete only when:

1. every original source file is screened;
2. high-salvage sources are deep reviewed;
3. promoted mechanisms have an active route;
4. seed material is recoverable without reopening giant compendia;
5. rejected / conflicting material is explicitly identified;
6. the owning pages remain stronger than legacy detail.

---

# 4. Anti-restoration rule

V2 is **not** an instruction to restore old worldbuilding wholesale.

Do not revive by inertia:

- six cultures = six kingdoms;
- one regional personality;
- one costume / cuisine / architecture per culture;
- RPG-class guilds as default institutions;
- literal old pantheon cosmology;
- unsupported magic / technology;
- fantasy-compound place names;
- one mastermind causing every crisis;
- old exact maps / borders merely because they are detailed.

The test is always:

> **Can the useful mechanism survive after the obsolete wrapper is removed?**

# 7. Initial cross-volume findings

The screen already shows several themes that deserve stronger active preservation.

## A. Institutional federalism

Repeated legacy material assumes:

- central standards;
- local / regional chapters;
- partial branch autonomy;
- rotating meetings;
- splinters if central authority overreaches.

This applies beyond guilds.

Potential relevance:

- religions;
- professional associations;
- route compacts;
- Council-linked networks;
- underworld organizations.

## B. Beneficiaries of disorder

Legacy repeatedly gives crises an economy.

Examples:

- pirates create work for escorts / repair;
- route closure enriches alternates;
- smuggling fills supply gaps;
- crackdown empowers compliant actors;
- shortages benefit storage / credit holders;
- centralization benefits large organizations more than small members.

This is now active through the Stakeholder Reaction Matrix.

## C. Local adaptation beats regional essence

Even old theme-heavy notes repeatedly contain better sub-details:

- border towns blend building methods for actual weather / route needs;
- recipes change near markets;
- young speakers level dialects through travel;
- branches adapt standards locally;
- itinerant groups move seasonally rather than embodying one "nomad culture."

Those mechanisms survive.

## D. Maintenance is political

Across architecture, roads, Underpass, weapons, guilds and current events, old notes repeatedly return to:

- repairs;
- delayed maintenance;
- replacement parts;
- toll funding;
- who is responsible;
- who benefits from neglect.

This deserves stronger cross-system use.

## E. Information follows work

Legacy often places information in:

- guild correspondence;
- merchants;
- travelers;
- scribes / records;
- sailors;
- market meetings;
- festivals.

This aligns strongly with the rebuilt Port / Three Moons information architecture.

## F. Successful resistance matters

Legacy story material contains:

- villages resisting rumor;
- guilds stabilizing prices;
- kings refusing pressure;
- quiet local defenders;
- policies that blunt damage.

These should be retained because the adaptive Villain requires failures / counter-dominoes.

# 8. World / material-life promotions from the V2 pass

Promoted from Volumes 01–05:

- local border exceptions: small-goods duties, marriage / apprenticeship recognition, water schedules, narrow reciprocal guild / passage arrangements;
- seasonal route memory: old passes / roads having different political meaning by season;
- failed-expansion archaeology: abandoned terraces, unfinished walls, lost mines, stopped roadbeds;
- Underpass route-control ambiguity: the same gate / fort can provide real protection while also extracting tolls and privilege;
- responsibility-based occupational initiation: status follows trusted work rather than decorative trials;
- repair infrastructure as a settlement function at transfer points;
- food history in which work / travel foods become comfort or identity foods after conditions change;
- temporary convergence meals as one path by which contact cuisine later becomes local tradition.

Deliberately **not** restored:

- old regional personality templates;
- one cuisine / architecture per region;
- ornate guild rituals as universal practice;
- named legacy towns without current naming history;
- old one-region-one-state politics.

These promotions demonstrate the V2 rule:

> salvage the mechanism beneath the wrapper.
