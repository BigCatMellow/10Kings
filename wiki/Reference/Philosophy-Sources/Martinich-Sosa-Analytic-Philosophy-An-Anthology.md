# 4. Political categories are not neutral containers

## Source-grounded research direction

The philosophy-of-language readings ask, in different ways, how:

- expressions refer;
- meaning relates to use / intention / reference;
- two expressions can concern the same thing while presenting it differently;
- shared language succeeds or fails at communicating a proposition.

These are technical philosophical problems.

They should not be flattened into a claim that "all political language is subjective."

## 10Kings application

Instead, use them to sharpen specific story problems.

### Same event, different description

One incident might be described as:

- piracy;
- privateering;
- resistance;
- seizure;
- enforcement;
- theft.

The physical event does not change.

Its political meaning does.

### Same rule, different referent

"Port defense" can mean:

- armed harbor watch;
- permanent military force;
- convoy support;
- foreign guarantees;
- emergency mobilization.

People can agree verbally while imagining different institutions.

### Same name, different institutional object

"The guild" may refer to:

- a central office;
- a regional branch;
- a profession as a whole;
- delegates currently assembled in Port.

This matters because the current world explicitly rejects unified institutional minds.

# 5. Meaning, contracts, and multilingual politics

The setting already contains:

- translators;
- contract scribes;
- court interpreters;
- guild representatives;
- harbor clerks;
- competing official versions of agreements.

The analytic-language material suggests a useful discipline:

> when a dispute depends on a word, ask what proposition each party believes the word commits them to.

That can generate grounded conflicts around:

- **neutrality**;
- **customary access**;
- **strategic cargo**;
- **recognized branch**;
- **emergency authority**;
- **reasonable inspection**;
- **pirate**.

This is a better use of the anthology than trying to extract political doctrine from sections the uploaded file does not contain.
