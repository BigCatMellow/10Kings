# Cultural Analogue Coverage Assessment — V1

## Status

**Research / worldbuilding assessment — not canon.**

This page audits the current world against the older design method:

> **use several real-world societies as problem-solving research sources, borrow specific mechanisms rather than whole cultures, and combine different sources differently for different communities inside the same broad region.**

The purpose is to identify what has survived, what has been improved, and what still needs to be rebuilt.

# 1. Executive finding

## Strongly developed

The current world already has strong systems for:

- avoiding one-culture-per-region design;
- culture crossing political / ecological borders;
- diaspora and migrant communities;
- cultural bleed creating third traditions;
- class / occupation / neighborhood / generation differences;
- food;
- architecture;
- clothing / material culture;
- household life;
- arts / leisure;
- festivals / life-cycle rituals;
- cross-regional transmission;
- contact zones;
- political diversity inside each region;
- ordinary-life vertical slices.

## Underdeveloped

The main missing layer is:

> **specific local community ↔ specific real-world comparative research.**

Current regional owners often say:

> useful inspiration pools include A, B, C, D, E.

Current vertical slices then create:

> a workshop household / harbor household / river-market household / caravan neighborhood.

But the project usually does **not yet say**:

> this particular workshop community uses Welsh mining-community research for labor institutions, Andean mining research for settlement / extraction relationships, and Japanese craft-lineage research for apprenticeship — while another Stone Hills community uses a different combination.

That is the older method the user remembers.

It should be restored in a more disciplined form.

# 3. What the current culture work already solved

The newer culture pass should **not** be discarded.

It improved the older work in several important ways.

## Region is no longer ethnicity

Current owners explicitly reject:

- one Earth culture per region;
- one personality per region;
- one costume;
- one food identity;
- one architecture silhouette.

That is a major improvement.

## Community is generated by lived systems

Current vertical slices derive culture from:

- work;
- household;
- class;
- law;
- water;
- land;
- risk;
- storage;
- route use;
- guilds;
- migration.

This is stronger than the legacy "blend three aesthetics and name a tribe" approach.

## Contact is productive

Current Phase 7 supports:

~~~text
A + B + local conditions + generations
→ C
~~~

That is exactly the mechanism needed for believable cultural blending.

## Political diversity is strong

The polity vertical slices already provide distinct internal anchors that can receive different cultural research.

Examples:

- Stone Hills industrial civic jurisdiction versus rural / forest-edge constituencies;
- North Coast compact harbors, islands, clan jurisdictions, inland districts;
- Low Rivers transfer-market center, estates, cooperatives, village / water institutions;
- High Roads northern, western-gate, and central switching polities plus herders / caravan actors;
- Longwood western compact, interior jurisdictional alliance, southern market polity, use-right communities;
- Old Cities upstream, downstream, and coastal sovereign rivals.

Therefore the missing work does **not** require inventing a new internal map.

The internal differentiation already exists.

# 4. Legacy method worth restoring

Legacy culture work contains a useful research pattern.

## Nomadic comparative pool

The preserved nomad research explicitly examined:

- Dukha / Tsaatan;
- Nenets;
- Qashqai;
- Rabari;
- Fulani / Fulbe;
- Tuareg;
- Pokot.

It looked at specific mechanisms such as:

- seasonal migration;
- highland / lowland transhumance;
- herd economics;
- clan structure;
- textile / portable craft;
- oral history;
- water / pasture access;
- gendered household property;
- relationships with settled authorities;
- route disruption by expanding states / industry.

This research pool is still valuable.

## Combined-culture experiments

Legacy work also deliberately tested combinations such as:

- Appalachian + highland pastoral / Central Asian / Andean mechanisms;
- Appalachian + river cultures;
- Appalachian + traveling craft / musical traditions;
- North Atlantic + Ainu / Japanese maritime traditions;
- West African communal structure + Southeast Asian agriculture + Appalachian orchard traditions;
- Amazonian + Slavic / Baltic + East Asian forest practices.

The old **names and costume-forward implementations** should not be restored automatically.

The valuable method is:

> **different communities inside the same world area receive different combinations of mechanisms.**

# 5. Stone Hills assessment

## Current strengths

Already supported:

- major industrial civic jurisdiction;
- mine / extraction power;
- guild masters;
- worker / reform networks;
- rural / forest-edge communities;
- mixed workshop households;
- mining + craft + farming economies;
- food dependence;
- strategic metal politics.

Current broad research pools:

- Scottish / Welsh mining communities;
- Appalachian mining / craft communities;
- Andean highland mining settlements;
- Ethiopian / Yemeni upland stone architecture;
- Japanese / Chinese craft lineages;
- Central European / Balkan mountain towns.

## Missing layer

Those sources are not yet assigned to distinct Stone Hills communities.

We still need at least **3–4 anchor community profiles**, such as:

### A. Major industrial / mine civic district

Research questions:

- worker housing / mutual aid;
- mine-owner / civic-government relationship;
- dangerous-trade welfare;
- union / guild / apprenticeship overlap;
- multi-generation technical reputation.

### B. Upland mixed mine / smallholder settlement

Research questions:

- farming + extraction in one household economy;
- seasonal labor;
- highland transport;
- communal risk;
- stone / terrace building.

### C. Small craft town / hereditary workshop network

Research questions:

- craft lineage;
- apprenticeship residence;
- workshop inheritance;
- quality / reputation systems;
- local versus large-guild authority.

### D. Western foothill / contact community

Research questions:

- Low Rivers / Longwood cultural bleed;
- farming + repair;
- migrant labor;
- bilingual / mixed naming;
- local resistance to industrial centralization.

## Assessment

**YELLOW.**

Stone Hills has excellent economic / political differentiation.

It needs **source-specific cultural differentiation attached to those existing communities**.

# 11. Port assessment

## Current strengths

Port is unusually strong structurally.

It already uses explicit analogical research for:

- external neutral-city structure;
- internal cultural / civic behavior.

It also has developed constituencies:

- established harbor families;
- merchants / factors;
- workers;
- guilds;
- migrants / displaced people;
- foreign communities;
- autonomy reformers;
- neutrality institutionalists;
- labor / neighborhood reformers;
- centralizers;
- localists.

Culture owners also support:

- mixed households;
- migrant neighborhoods;
- secondhand culture;
- local third traditions;
- generational Port identity.

## Missing layer

Port needs fewer regional analogues and more **specific neighborhood / diaspora histories**.

Need 3–5 concrete examples such as:

- old harbor-worker neighborhood;
- long-settled North Coast-descended district now culturally Port-born;
- High Roads merchant / clerk diaspora;
- Low Rivers labor / food-market migration neighborhood;
- mixed guild-professional quarter;
- refugee / displaced community from a specific current or older event.

Each should answer:

> what did this group bring, what changed in Port, and what returned outward?

## Assessment

**YELLOW / strong foundation.**

Port's missing work is **ethnogenesis and neighborhood history**, not macro culture.

# 12. Nomads / itinerants assessment

## Current strengths

The owner is structurally excellent.

It establishes:

- multiple mobile livelihoods;
- circuits rather than wandering;
- fixed attachments despite mobility;
- access arrangements;
- property;
- jurisdictional variation;
- kin networks;
- information transmission;
- internal class differences;
- relationship with guilds / faiths / Port / High Roads / Underpass.

## Major missing work

No actual mobile people / circuit has yet been fully instantiated.

The owner itself lists as open:

- whether the Appalachian-influenced concept is one people, related peoples, or broad network;
- origin;
- exact circuits;
- livelihoods;
- language;
- winter quarters;
- legal attachment;
- taxation;
- grazing / stopping agreements;
- guild status;
- education;
- marriage / inheritance;
- burial;
- political organization.

This is the clearest **RED** area.

## Minimum needed

Develop **at least three distinct mobile systems**, not one "nomad people."

### A. Appalachian-influenced repair / ballad / seasonal-work network

Use legacy Appalachian material for:

- kin;
- ballad memory;
- repair / reuse;
- path knowledge;
- mutual aid;
- suspicion of extractive authority.

Then combine with one or more genuinely mobile comparative traditions.

Do not copy old Ridge-Roamer / Blueline names.

### B. Highland pastoral / transhumant circuit

Use legacy comparative pool:

- Qashqai;
- Rabari;
- Fulani;
- Pokot;
- potentially Dukha / Nenets only where ecology actually fits.

Focus on:

- seasonal pasture;
- herd economy;
- property;
- water;
- access negotiation;
- settled kin.

### C. Caravan / itinerant service households

Focus on:

- guiding;
- animal handling;
- repair;
- trade;
- information;
- recurring inns / markets / customers.

Could overlap culturally with High Roads without being identical to settled High Roads people.

### Optional D. River / boat mobile households

Current world supports this structurally, but comparative research is thin.

This should receive fresh research before canonization.

## Assessment

**RED.**

Nomads are not conceptually missing.

They are **uninstantiated**.

This should probably be the first major culture-research implementation after the assessment.

# 16. What we still need — priority order

## Priority 1 — community-to-analogue matrix

Build a new research matrix with rows for **actual in-world community types**, not regions.

For each row record:

| Field | Question |
| --- | --- |
| In-world community | Which actual local community / social formation? |
| Existing support | Which current owners already establish it? |
| Research sources | Which 2–4 real-world societies / cases help answer specific problems? |
| Mechanism borrowed | Labor? kin? access? architecture? apprenticeship? water? mobility? |
| Explicit non-borrow | What should *not* be copied? |
| Local history | Why did this form arise here? |
| Neighbors | Which nearby / migrant groups altered it? |
| Internal disagreement | Who inside the community rejects / modifies the practice? |
| Transmission | What does this community export / borrow? |
| Canon status | research / provisional / promoted |

### Target

Start with **3–5 communities per region**, not dozens.

That produces enough variation to break the "region = people" reflex without encyclopedic overbuilding.

---

## Priority 2 — instantiate three mobile circuits

Nomads / itinerants should be the first implementation target.

Reason:

- the structural owner is already strong;
- legacy comparative research already exists;
- mobile peoples connect every other cultural system;
- they improve movement / information / story texture immediately.

Deliverables:

1. Appalachian-influenced repair / ballad circuit;
2. highland pastoral / transhumant circuit;
3. caravan / itinerant service circuit.

Each must have:

- annual / multi-year route;
- economic reason to move;
- legal access at each stop;
- settled relationships;
- internal class / household variation;
- specific comparative sources.

---

## Priority 3 — differentiate Old Cities city by city

This has high payoff because the current phrase **Old Cities** can still encourage accidental homogenization.

Assign distinct comparative research to:

- OC-U;
- OC-D;
- OC-C;
- one hinterland irrigation community.

Do not make each city an Earth analogue.

Give each a different mechanism mix.

---

## Priority 4 — split North Coast and Longwood research pools locally

Both have diverse source pools that can easily collapse into:

- generic northern fisher;
- generic forest community.

Assign sources to:

- island / harbor / inland in North Coast;
- western edge / interior / southern market / managed woodland in Longwood.

---

## Priority 5 — Stone Hills / Low Rivers local community mapping

These regions already have strong social / political mechanics.

They need their broad research pools attached to:

- actual town types;
- household systems;
- labor / land arrangements.

---

## Priority 6 — Port diaspora / contact communities

After regional / mobile communities are more concrete, build Port neighborhoods partly from their actual migration histories.

This prevents Port from being designed from generic cosmopolitanism.

# 17. Research depth rule

Do not write:

> "this community is inspired by the Qashqai, Appalachians, and Andeans."

Write:

> **Qashqai research is being used to test highland/lowland seasonal movement and household herd economics; Appalachian research is being used for ballad memory / repair culture / extractive-authority suspicion; Andean research is being used for vertical ecological exchange.**

Then ask:

> what would those mechanisms become after centuries inside this world's law, religion, trade, ecology, and neighboring cultures?

That final transformation is the in-world culture.

---

# 18. Minimum completion target

The world does **not** need every village researched.

A strong next milestone would be:

- Stone Hills: 4 mapped communities;
- North Coast: 4;
- Low Rivers: 4;
- High Roads: 5;
- Longwood: 5;
- Old Cities: 4;
- Port: 4 neighborhood / diaspora communities;
- mobile peoples: 3 circuits;
- contact zones: 3 synthesized communities.

Total:

> **36–40 anchored community profiles**

These can be brief.

The goal is not 40 encyclopedic articles.

A profile can be 1–2 pages if it clearly establishes:

- origin;
- livelihood;
- institutions;
- comparative research;
- local transformation;
- internal variation;
- neighbors.

That is enough to make the world feel populated by **communities rather than regions**.

# 19. Assessment conclusion

The culture project is further along than the missing analogue layer initially makes it appear.

The current world already knows:

- how culture forms;
- how it moves;
- how it changes;
- how class and work alter it;
- how institutions enter daily life;
- how regions avoid becoming monocultures.

What it lacks is the **middle layer between region and household**:

> **named or at least stable local communities with their own historical mixtures and clearly documented comparative research.**

That is the next useful worldbuilding task.

The strongest implementation order is:

~~~text
ASSESSMENT
→ community-to-analogue matrix
→ three mobile circuits
→ Old Cities city-by-city
→ North Coast / Longwood local splits
→ Stone Hills / Low Rivers / High Roads completion
→ Port diasporas
→ contact-zone synthesized communities
→ promote only what survives stress testing
~~~

This restores the user's original niche-comparison method without undoing the stronger worldbuilding system developed since.
