# N1 / R1 / P1 Naming Micro-Sets — V1

## Status

**Failed lexical-generation experiment — retained as naming QA provenance, not an active name source.**

This page records an important design failure.

The experiment began after [Neighboring Name Pressure Test — V1](Neighboring-Name-Pressure-Test-V1.md) showed that isolated candidate names were converging on one authorial sound. The attempted correction generated several names from each provisional language cluster at once.

That solved the **sameyness** problem better than isolated generation.

It still failed the more important rule in [Naming](../Culture/Naming.md):

> an opaque local-language form must be derived from enough actual linguistic / historical material to explain why speakers produced it.

The micro-set experiment instead did this:

~~~
site history
→ invent tiny one-use roots
→ combine them into a plausible-sounding word
→ call the result historically derived
~~~

That is still reverse engineering.

# 2. What the experiment did successfully

The lexical forms failed.

Several **non-lexical results remain useful**.

## N1

The principal mainland political harbor is grounded in:

- a sheltered mainland inlet / bay;
- freshwater;
- inland road access;
- later recurring maritime coordination.

NC-I still needs an island name grounded in an actual inherited linguistic layer.

NC-R still works as an older settlement at a dependable creek / lower valley before becoming a transfer roadhead.

## R1

G1 can plausibly carry an old hydronym older than LR-A.

LR-M still works as an older crossing / ferry settlement that later becomes the major head-of-navigation market.

The Stone Hills / Low Rivers foothill contact settlement still works as a mixed farming / craft / route market.

## P1

HR-C still begins around a dependable spring / spring-fed hollow before becoming a major switching and arbitration city.

HR-N's roadhead can still predate route bureaucracy as a pasture / water / resting settlement.

HR-W can still grow from an ordinary pass-approach settlement with water, repair, toll, and defensive importance.

These histories are valid naming **sources**.

They do not themselves provide local words.

- **North Yard** — caravan shorthand for NC-R;

These remain provisional where their owner pages mark them provisional.

They survive because the setting already explains:

- who says them;
- what they mean;
- why those speakers would use those words.

---

# 4. Correct role of a micro-set

The micro-set method is **not discarded**.

Its proper sequence is later:

~~~
develop / recover real linguistic history
→ derive several ordinary names from that history
→ compare the names as a micro-set
→ reject accidental authorial repetition
→ test neighboring-language pressure
~~~

The micro-set is therefore a **QA stage after derivation**, not a generation stage before derivation.

---

# 5. New naming gate

A local opaque form should not become an active candidate until the project can answer:

1. What real language layer produced it?
2. What vocabulary / naming element already exists independently of this one place?
3. What ordinary phrase, lineage, feature, or inherited proper name did speakers actually use?
4. What historical sound / spelling change produced the modern form?
5. Can that derivation work for more than one word without inventing a miniature dictionary solely to support the candidate?

If those questions cannot be answered, leave the local name open.
