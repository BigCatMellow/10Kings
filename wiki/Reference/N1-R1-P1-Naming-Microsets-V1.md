# N1 / R1 / P1 Naming Micro-Sets — V1

## Status

**Provisional naming QA / lexical tests — not canon language inventories.**

This page implements the micro-set requirement established by:

- [Neighboring Name Pressure Test — V1](Neighboring-Name-Pressure-Test-V1.md)
- [Minimal Naming Profiles — V1](Minimal-Naming-Profiles-V1.md)
- [Language and Naming Topology — V1](Language-and-Naming-Topology-Test-V1.md)

The rule is:

> **A local-language name does not pass because it works alone. It must work beside other names from the same historical naming ecology and beside names from neighboring clusters.**

This page tests three bounded sets:

- N1 — northern coastal / mainland chain;
- R1 — eastern river / lowland cluster;
- P1 — plateau / interior High Roads cluster.

No roots on this page should be treated as a general dictionary.

---

# 1. N1 micro-set

## Objects

The N1 set needs to cover three different North Coast naming situations:

1. NC-M principal political harbor;
2. NC-I principal island / island polity;
3. NC-R local roadhead settlement.

This is better than generating one "North Coast name" because the three places have different site histories and different political relationships.

---

## N1-A — principal mainland harbor

### Site source

Already established in [Political Naming Source Vertical Slices — V1](Political-Naming-Source-Vertical-Slices-V1.md):

- sheltered mainland inlet / bay;
- reliable freshwater outlet;
- practical inland road access;
- later meeting / convoy / political center.

### Micro-roots for this test only

- **au** — protected inner water / sheltered inlet;
- **vor** — freshwater cut / stream mouth.

### Compound

~~~
au + vor
→ Auvor
~~~

### Candidate

> **Auvor**

The name describes the harbor site, not later state power.

It can survive even if the central government moves elsewhere.

---

## N1-B — NC-I principal island

### Minimal site-history test

NC-I needs a physical island name before it needs a constitutional label.

V1 tests a principal island that is:

- clearly offshore from the main mainland harbor chain;
- large enough to contain several settlements / local jurisdictions;
- commonly approached through one long-used landing / inner shore.

The oldest island label need not describe the whole island precisely.

A practical mainland / sailor distinction such as "outer island / outer land" can become the inherited name.

### Micro-roots for this test only

- **or** — outer / offshore;
- **ai** — island / separated land.

### Compound

~~~
or + ai
→ Orai
~~~

### Candidate

> **Orai**

### Political relationship

Orai can plausibly serve as:

- island name;
- island-polity common name.

That follows the structural result from [Polity and Place Naming Relationship Test — V1](Polity-and-Place-Naming-Relationship-Test-V1.md).

It does not decide whether Orai is legally a confederate, dependency, protectorate, tributary, or sovereign associate.

---

## N1-C — NC-R local roadhead

### Site-history constraint

NC-R should predate its modern role as "North Yard."

The best minimal source is:

> a small settlement beside a dependable creek / sheltered lower valley where the southbound road begins climbing toward the shoulder.

The roadhead grows there because:

- water is available;
- carts can assemble on lower ground;
- the pass approach naturally narrows beyond it.

### Micro-roots for this test only

- **se** — creek / small running water;
- **vu** — sheltered lower ground / valley pocket.

### Compound

~~~
se + vu
→ Sevu
~~~

### Candidate

> **Sevu**

Common caravan shorthand remains:

> **North Yard**

The two forms serve different social layers.

A resident can plausibly say:

> Sevu.

A caravan worker can plausibly say:

> North Yard.

# 2. N1 internal QA

## Candidate set

- **Auvor**
- **Orai**
- **Sevu**

## Shared behavior

The set uses:

- more vowel adjacency than W1 / P1;
- several open syllables;
- a mix of vowel-final and consonant-final outcomes;
- ordinary coastal / geographic semantic sources.

## Variation

The names do not all share:

- one ending;
- one syllable count;
- one consonant frame.

### Auvor

Two-part mainland harbor compound with final consonant.

### Orai

Vowel-rich island form.

### Sevu

Short local settlement form ending in a vowel.

## Pressure result

**PASS.**

The set reads as related without looking mechanically generated.

---

# 3. N1 external comparison

Compare against current provisional passes:

- Kavel / Varel — W1;
- Naret / Talir — S1.

Auvor / Orai / Sevu differ through:

- vowel sequencing;
- fewer repeated -el / -ir / -et style endings;
- more open coastal forms.

They remain readable and are not caricatured.

**PASS.**

---

# 4. N1 disposition

The held first-pass **Kelan** is superseded by this set.

Current working N1 candidates:

- NC-M center → **Auvor**;
- NC-I → **Orai**;
- NC-R local town → **Sevu**.

Common-language layer:

- Sevu → **North Yard** in caravan shorthand.

The maritime-polity adoption mechanism still survives:

> repeated coordination at the principal harbor can cause the harbor's name or an agreement named for it to become a wider political label.

But the polity-level decision should be retested using **Auvor**, not Kelan.

# 5. R1 micro-set

## Objects

The R1 set needs:

1. G1 hydronym;
2. LR-M local civic name;
3. the established Stone Hills ↔ Low Rivers foothill contact settlement / market (CZ-1).

This deliberately mixes:

- one very old river name;
- one major administrative / commercial city;
- one contact-zone settlement.

That tests whether R1 naming has historical depth rather than one productive suffix.

---

## R1-A — G1 river

### Naming layer

G1's name should be older than LR-A and older than much of its administrative standardization.

V1 therefore treats the river name as a **fossil hydronym**.

Its original internal segmentation is not assumed to remain transparent.

### Candidate

> **Daroa**

### Why no root breakdown is supplied

That is intentional.

The river is one of the oldest names in the basin.

Later R1 speakers can inherit **Daroa** without knowing exactly what its earliest speakers meant.

This is more plausible than making every old hydronym transparently compositional in the modern language.

---

## R1-B — LR-M local civic name

### Site-history refinement

The G1 head-of-navigation market already supports an older crossing / ferry before its later mode-transfer dominance.

V1 selects the crossing as the local naming cause.

The later name **Last Quay** remains a merchant / common-language exonym.

### Micro-roots for this test only

- **da** — crossing / ferry place;
- **sei** — firm or raised landing bank.

### Compound

~~~
da + sei
→ Dasei
~~~

### Candidate

> **Dasei**

### Name layers

local civic name:

> Dasei

interregional commercial name:

> Last Quay

This is a strong two-name relationship because each name encodes a different period of the settlement's history.

---

## R1-C — Stone Hills / Low Rivers foothill contact market

### Existing place function

[Border Towns](../Places/Border-Towns.md) already requires a Stone Hills ↔ Low Rivers foothill craft / farming corridor characterized by:

- mixed farming and craft households;
- food moving uphill;
- tools / repair moving downhill;
- labor migration;
- bilingual / mixed communities.

[Political Adjacency and Border-Interface Test — V1](Political-Adjacency-and-Border-Interface-Test-V1.md) further implies CZ-1, a foothill market settlement in this contact zone.

### Minimal naming source

V1 tests a settlement around:

- cultivated / cleared ground at the mouth of a foothill route;
- an old crossing used by both agricultural and upland traffic.

### Micro-roots for this test only

- **ome** — worked field / cleared productive ground;
- **da** — crossing / transit point.

### Compound

~~~
ome + da
→ Omeda
~~~

### Candidate

> **Omeda**

### Contact-zone caution

Omeda is the R1-side / common local form tested here.

A W1 form, translated name, or mixed pronunciation may coexist later.

Do not force one official name on the whole contact community.

---

# 6. R1 internal QA

## Candidate set

- **Daroa** — fossil hydronym;
- **Dasei** — crossing / landing settlement;
- **Omeda** — productive-ground / crossing contact settlement.

## Shared behavior

- open syllables are common;
- vowel-final or vowel-sequence forms are normal;
- **da** can function productively in later settlement names;
- the ancient river name does not have to use the productive modern morphology.

## Variation

The set avoids making every place:

- two syllables;
- final -en;
- built from the same suffix.

Daroa is deliberately older-looking.

Dasei and Omeda show a later productive layer.

## Pressure result

**STRONG PASS.**

This is a more convincing naming ecology than isolated **Ralen**.

---

# 7. R1 external comparison

Against:

- Auvor / Orai / Sevu — N1;
- Kavel / Varel — W1;
- Naret / Talir — S1.

R1 has:

- more open syllable sequences than W1;
- productive **da** in settlements;
- a distinct fossil hydronym layer.

There is some vowel richness shared with N1, which is acceptable because both are ordinary human languages and contact is extensive.

The actual name shapes remain sufficiently distinct.

**PASS.**

---

# 8. R1 disposition

The held first-pass **Ralen** is superseded.

Current working R1 candidates:

- G1 → **Daroa**;
- LR-M local city → **Dasei**;
- CZ-1 foothill contact market → **Omeda**.

Existing common-language form:

- Dasei → **Last Quay**.

The river-to-polity naming mechanism can now be retested as:

> Daroa river / Daroa basin  
> → possible Daroa political common name for LR-A.

That remains a separate polity-adoption question.

# 9. P1 micro-set

## Objects

The P1 set needs:

1. HR-C central switching / arbitration city;
2. HR-N High Roads-side North Shoulder roadhead / local polity center;
3. HR-W principal Western Gate settlement.

The three places should share an older plateau naming substrate without becoming "route names."

---

## P1-A — HR-C

### Site source

Already established:

- reliable upland spring / spring-fed hollow;
- later route convergence;
- later arbitration reputation.

### P1 compression rule

P1 compounds may lose unstressed vowels at a frequently used boundary.

For this test only:

- **me** — spring / dependable water point;
- **esk** — sheltered hollow / basin.

Earlier transparent form:

~~~
me + esk
→ meesk / mesek
→ Mesk
~~~

### Candidate

> **Mesk**

The exact historical phonetic path is provisional.

The important test is that a mundane water-source phrase can compress into a compact modern place name.

---

## P1-B — HR-N local roadhead / polity center

### Site-history source

The High Roads-side roadhead should also predate "South Yard."

V1 tests an older settlement where:

- lower plateau pasture is reliable;
- animals can rest / exchange before the steep shoulder;
- a small water source supports herders and travelers.

### Micro-roots for this test only

- **ko** — grazing ground / pasture;
- **rad** — slope-foot / lower shoulder.

### Compound

~~~
ko + rad
→ Korad
~~~

### Candidate

> **Korad**

Common caravan shorthand remains:

> **South Yard**

The local polity can provisionally be referred to through Korad without making it representative of all High Roads.

---

## P1-C — HR-W principal settlement

### Site-history source

HR-W needs a concrete local settlement on the High Roads side of the Western Gate.

V1 tests a town that began on:

- a broad rock / gravel shelf;
- beside a dependable well or seep;
- just below the steepest western pass approach.

It later becomes important for:

- tolls;
- repair;
- defense;
- Stone Hills trade.

### Micro-roots for this test only

- **tav** — broad shelf / level shoulder;
- **rek** — well / dependable seep.

### Compound

~~~
tav + rek
→ Tavrek
~~~

### Candidate

> **Tavrek**

The compact consonant boundary is intentional.

It is a local plateau form, not a merchant-friendly translation.

---

# 10. P1 internal QA

## Candidate set

- **Mesk**
- **Korad**
- **Tavrek**

## Shared behavior

The set permits:

- final consonants;
- compact compound boundaries;
- greater consonant weight than N1 / R1;
- short inherited local forms.

## Variation

- Mesk is highly compressed;
- Korad is an ordinary two-root compound;
- Tavrek preserves a heavier internal cluster.

The names do not all use one suffix.

## Pressure result

**STRONG PASS.**

This creates a visible P1 naming texture without resorting to apostrophes, exotic clusters, or one gimmick.

---

# 11. P1 merchant / legal layer

High Roads is multilingual.

Therefore a local P1 name may be written or pronounced more openly in foreign commercial records.

Possible non-canon examples of the mechanism:

- Mesk → foreign speakers insert a vowel in speech;
- Tavrek → some records preserve the local spelling while speakers simplify the cluster;
- Korad → may travel with almost no adaptation.

The wiki should record the **local form** first.

Do not replace local names with merchant pronunciations merely because outsiders find them easier.

# 17. Promotion boundary

These are still **provisional reference names**.

The micro-set pass is a naming-quality milestone, not automatic canon promotion.

Before moving them into owner prose as active place names:

1. test exact map placement against the site histories;
2. check whether the political history still supports place → polity adoption;
3. check the roster for unwanted real-world / legacy collisions if one becomes apparent;
4. promote only the names actually needed by current world / story work.

Do not name every remaining settlement merely because the method now works.

---

# 18. Next useful naming work

The next naming task should be narrow:

## Retest polity adoption

- Does **Daroa** work as the common political name of LR-A as well as the river?
- Does the North Coast maritime polity inherit **Auvor** directly, become **the Auvor Compact**, or keep a separate compact name?
- Does **Varel** remain a useful SH-A metonym after the surrounding-name pass?

## Then stop

Do **not** move immediately into F1 or a complete map-name inventory unless a concrete Longwood / story need requires it.

The method has now demonstrated that it can generate, reject, and replace names in a controlled way.
