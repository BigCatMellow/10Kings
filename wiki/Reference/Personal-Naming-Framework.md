# Personal Naming Framework

## Status

**Reference / design framework — not canon.**

This page extends [Naming](../Culture/Naming.md) from place names to people.

It does not assign final naming systems to regions and does not promote any provisional character name.

Related:

- [Language History and Naming Audit](Language-History-and-Naming-Audit.md)
- [Social Fabric](../Social-Fabric.md)

## Core rule

Personal names should come from **kinship, law, language, religion, class and migration history**, not from “what sounds like this region.”

A region can contain several naming systems at once.

The same system can also cross regional borders through:

- religion;
- dynasty;
- guild membership;
- migration;
- conquest;
- marriage;
- urban fashion;
- diaspora.

## Name components that can coexist

A person's socially complete name might draw from several layers:

- given name;
- household or family name;
- patronymic / matronymic;
- clan / lineage;
- house name;
- place byname;
- occupation or guild byname;
- religious or initiation name;
- title / office;
- nickname;
- legal transliteration used outside the home language.

Not everyone needs all of these.

Class and institution should affect how many components are recorded.

## Legal name versus social name

A useful worldbuilding distinction is:

**the name written in a contract may not be the name used at home.**

Examples of mechanisms to test later:

- a Highridge contract uses a standardized transliteration;
- a Port clerk shortens or respells a migrant name;
- a religious initiate adds a devotional name;
- a married noble uses a house name publicly while retaining a birth-line name in inheritance records;
- a craft worker is known by an occupational byname that becomes hereditary only later.

This lets naming reveal institutions without requiring exposition.

## Marriage

Do not decide on one world-wide rule.

Possible systems include:

- neither partner changes name;
- one joins the other's house;
- children inherit one line;
- children alternate lines;
- both lineages are recorded legally;
- a household adopts a residence name;
- elite marriages create compound political names;
- local custom and state law disagree.

Mixed marriages are especially useful tests because they force systems to interact.

## Class

Names can signal access to bureaucracy.

Possible contrasts:

- elites preserve long genealogical forms;
- ordinary people use one given name plus a local byname;
- guild members gain an institutional form used in contracts;
- migrants have names simplified by officials;
- old families insist on archaic spellings;
- newly wealthy families revive or invent lineage claims.

Do not assume longer names always mean higher status in every culture.

## Religion

The nine trans-regional faiths may affect naming without creating nine separate naming systems.

Possible effects:

- founder / teacher names become popular;
- initiation names;
- burial names;
- taboo names;
- recurring devotional elements;
- names revived by reform movements;
- saints / exemplars translated differently across languages.

Because the faiths cross borders, the same religious name can appear in several regional forms.

## Guild and profession

Professional identity can create:

- workshop bynames;
- master names;
- ship names used as personal identifiers;
- caravan house names;
- apprenticeship names;
- guild-record spellings.

A professional byname can eventually become a hereditary surname even after descendants leave the trade.

## Migration and Port

Port is a major naming engine.

A three-generation migrant family can plausibly experience:

```text
home-language form
→ Port clerk transliteration
→ neighborhood shortening
→ local pronunciation shift
→ third-generation legal family name
```

Different branches of the same family may emerge with different spellings.

Port-born people may also adopt names whose components come from several traditions without feeling “mixed” to them.

## Highridge and standardized forms

Because Highridge is strongly tied to contracts, arbitration and multilingual travel, it is a plausible source of **recording conventions**.

That does not require a Highridge naming system to dominate.

Instead, Highridge scribes may standardize how foreign names are represented in:

- contracts;
- route permits;
- debt records;
- court proceedings;
- treaties.

Those record forms may later be mistaken for people's “real” names by outsiders.

## Political naming

Names can become political.

Examples:

- restoring an old spelling;
- rejecting a conqueror's family-name form;
- reviving pre-Convergence names;
- giving children names associated with a reform movement;
- changing a house name after a major defection;
- refusing an official transliteration.

This should be used sparingly but can connect culture to current politics.

## Wurdren test

### Current status

**Wurdren is a protected core story name.**

The correct question is not whether to replace it.

The question is what history makes it feel inherited.

### What needs to be learned

Before assigning an etymology, determine:

1. where he was born;
2. what language community named him;
3. whether the name was common in his generation;
4. whether younger people hear it as old-fashioned;
5. whether the current spelling is native or standardized;
6. whether friends shorten it;
7. whether the name travels easily across language communities;
8. whether his adventuring career caused one spelling / pronunciation to become internationally familiar.

### Strong possible direction

Because Wurdren is older and has traveled widely, his name could become a useful example of **a local name fossilized in an interregional spelling**.

That is only a design hypothesis.

Do not promote it until his origin is known.

## Current provisional roster

These remain unresolved:

- Orin Slatehallow
- Maris Bleakshore
- Rosana Meadowcroft
- Samir Tareh
- Naruin Mossglade
- Bahriyya Nazar
- Mira Stonebridge
- Gharic Coalveil
- Ilya Dravencrest

The problem is not that all are bad names.

The problem is that the list currently mixes:

- transparent fantasy surnames;
- real-world-adjacent names;
- invented names;
- region-coded aesthetic cues;

without a shared historical system.

### Rule

Do not “fix” them one by one by generating better-sounding names.

First define the relevant naming community.

Then test whether an existing name naturally fits.

## Minimum naming-community template

Before finalizing a cluster of personal names, answer:

### Kinship
- What counts as family for naming?
- Which line is recorded?
- Are surnames hereditary?

### Law
- What does the state or city require?
- Are names registered?
- Who can change them?

### Language
- What sounds / structures are common?
- What gets altered in translation?

### Religion
- Does initiation change names?
- Are some names sacred or avoided?

### Class
- How do elite and ordinary forms differ?
- Who cares about genealogy?

### Mobility
- How do foreign clerks write the name?
- What happens in Port / Highridge?

### Generation
- What names are old-fashioned?
- What names are newly fashionable?

If these are unknown, generate no final name list.

## Success test

A good personal naming system should let two people from the same region have obviously different naming histories because one is:

- urban;
- rural;
- guild-born;
- noble;
- migrant;
- religious;
- border-born;
- Port-born.

At the same time, related families should still look related across generations.

The goal is not exotic sound.

The goal is **social memory encoded in a name**.
