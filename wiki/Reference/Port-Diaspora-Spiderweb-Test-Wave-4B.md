# Port Diaspora Spiderweb Test — Wave 4B

## Status

**Challenge / promotion test — not setting canon.**

Sources:

- [Port Diaspora Comparative Research — Wave 4B](Port-Diaspora-Comparative-Research-Wave-4B.md)

## Promotion criteria

A diaspora type passes only if:

1. first-generation occupational concentration does not become permanent caste;
2. institutions can survive after occupations diversify;
3. second / third generations become Port-native rather than permanent extensions of origin regions;
4. return / circular influence exists;
5. diaspora identity can coexist with strong Port political identity.

---

# 1. D-1 — North Coast-descended Port community

## Occupational diversification

First generation plausibly clusters around:

- shipping;
- fish handling;
- repair;
- harbor labor.

Second / third generation can move into:

- other dock trades;
- guild work;
- clerical work;
- food / retail;
- municipal work.

**PASS.**

## Institution survival

Sea-loss / burial / mutual-aid / social institutions can survive after families leave fishing work.

**PASS.**

## Mixed-household test

Port household structure already supports:

- mixed-origin marriage;
- boarders;
- multi-generation households.

There is no reason this community remains endogamous.

**PASS.**

## Return influence

Port-born versions of:

- food;
- slang;
- guild practice;
- creature stories

can travel back through shipping / kin routes.

**PASS.**

## Port political identity

A descendant can favor stronger Port autonomy precisely because Port is home and ancestral North Coast governments are external.

**STRONG PASS.**

## Disposition

**P2-READY AS DIASPORA TYPE.**

---

# 2. D-2 — High Roads merchant / clerk network

## Occupational diversification

Rotating merchants remain networked.

Permanent descendants can enter:

- courts;
- guild offices;
- shipping finance;
- municipal records;
- unrelated professions.

**PASS.**

## Institution survival

Correspondence / lodging / credit / charitable institutions can continue serving:

- visiting merchants;
- settled descendants;
- mixed families.

**PASS.**

## Mixed-household test

Professional-network marriage may remain important initially, but Port residence creates ordinary cross-community contact.

A permanently closed merchant caste is not required.

**PASS with safeguard.**

## Return influence

Port legal / guild practice can move back through:

- letters;
- returning clerks;
- family branches;
- merchant apprentices.

**STRONG PASS.**

## Port political identity

Potential tension:

- family trade network may benefit from Port neutrality;
- settled descendants may favor greater Port political agency.

Those interests can diverge within one family.

**STRONG PASS.**

## Weakness

Do not allow "merchant diaspora" to become synonymous with wealth.

Need:

- low-paid clerks;
- failed factors;
- apprentices;
- widows / dependents;
- downward mobility.

This is a later class pass, not a structural blocker.

## Disposition

**P2-READY AS TRANSREGIONAL / PORT PROFESSIONAL DIASPORA TYPE.**

# 3. D-3 — Low Rivers labor / food-market migration community

## Occupational diversification

First generation:

- produce;
- food;
- warehouse;
- market labor.

Later generations:

- dock / guild / retail / civic / clerical work.

**PASS.**

## Institution survival

Food businesses / market ties may decline while:

- mutual aid;
- family networks;
- neighborhood institutions;
- food traditions

survive.

**PASS.**

## Mixed-household test

Very strong because:

- food markets;
- boarding;
- dock neighborhoods

are already mixed-contact environments.

**PASS.**

## Return influence

The strongest return loop:

> Low Rivers-derived practice → Port-born dish → upriver adoption as Port food.

This is exactly the world’s cultural-bleed model.

**EXCEPTIONAL PASS.**

## Port political identity

The abundance crisis makes it plausible for people with rural relatives to argue fiercely over Port food / migration policy while remaining strongly Port-identifying.

**PASS.**

## Disposition

**P2-READY AS DIASPORA TYPE.**

# 4. D-4 — Stone Hills skilled-worker diaspora

## Occupational diversification

First generation:

- skilled repair / metal / inspection.

Later descendants:

- guild administration;
- commerce;
- other trades;
- technical clerical work.

**PASS.**

## Institution survival

Technical vocabulary / mutual aid / apprenticeship practice can survive beyond the original occupation.

**PASS.**

## Mixed-household test

Skilled migration is occupational, not necessarily neighborhood-isolated.

Cross-community households are highly plausible.

**PASS.**

## Return influence

Extremely strong.

Guild / technical practices developed in Port can return through:

- apprentices;
- contracts;
- returning workers;
- cross-guild communication.

**PASS.**

## Port political identity

Credential centralization creates a useful split:

- migrants may appreciate portability;
- established Port workers may fear exclusion;
- descendants may defend Port local control.

No single diaspora political line.

**PASS.**

## Disposition

**P2-READY AS SKILLED-WORKER DIASPORA TYPE.**

# 5. Port-wide conclusions

## A. Diaspora should be modeled by generation

At minimum distinguish:

- recent arrival;
- long-term first generation;
- Port-born child;
- grandchild / later descendant;
- return migrant;
- mixed household.

"North Coast community" is not enough.

## B. Ancestry and political loyalty are different variables

A resident may retain:

- family language;
- food;
- religion;
- stories;
- kin

while strongly identifying politically as Port.

This is crucial for the final Port settlement.

## C. Institutions can preserve identity after jobs change

The strongest durable carriers may be:

- burial / mutual aid;
- religious houses;
- schools;
- clubs;
- correspondence networks;
- food businesses;
- guild branches.

Occupation should diversify faster than cultural memory.

## D. Port is an exporter of transformed culture

The migration model is not:

~~~text
region → Port
~~~

It is:

~~~text
region
→ Port migration
→ Port transformation
→ return / merchant / kin circulation
→ changed regional practice
~~~

This makes Port culturally powerful without making it culturally dominant.

---

# 6. Story consequence

This strengthens the main Port conflict.

"Port people" can include descendants whose grandparents came from:

- North Coast;
- High Roads;
- Low Rivers;
- Stone Hills;
- elsewhere.

Therefore the Villain's argument for Port agency need not depend on ethnic / ancestral unity.

A stronger basis is:

> **people who live under Port's institutions, bear Port's costs, and have built lives there have political interests as Port residents regardless of origin.**

This fits the broader thesis about:

- legitimacy;
- agency;
- who gets to decide.

But it also creates a constraint:

> **the Villain cannot honestly claim that Port speaks with one voice.**

Diaspora / labor / guild / merchant communities will disagree over:

- methods;
- neutrality;
- guild centralization;
- defense;
- sovereignty;
- war.

That disagreement should survive the ending.

---

# 7. Promotion result

All four diaspora mechanisms are **P2-ready as community types**:

- D-1 North Coast-descended Port community;
- D-2 High Roads merchant / clerk network;
- D-3 Low Rivers labor / food-market community;
- D-4 Stone Hills skilled-worker diaspora.

Do not canonize:

- exact neighborhood boundaries;
- exact institution names;
- demographic proportions;
- migration dates.

Promote only:

> Port contains multi-generation diaspora communities whose occupational and cultural forms transform into Port-native life while remaining connected to wider regional networks.
