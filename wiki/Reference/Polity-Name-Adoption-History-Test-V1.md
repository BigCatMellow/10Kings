# Polity Name Adoption History Test — V1

## Status

**Provisional naming-history mechanism test — lexical forms intentionally open.**

This page asks a narrower question than "what are the states called?"

It asks:

> **How could an ordinary place or geographic name historically become the common name of a polity?**

The previously tested invented lexical forms are no longer active. See:

- [Naming](../Culture/Naming.md);
- [Political Name Candidate Tests — V1](Political-Name-Candidate-Tests-V1.md);
- [N1 / R1 / P1 Naming Micro-Sets — V1](N1-R1-P1-Naming-Microsets-V1.md).

The adoption mechanisms remain useful because they do not depend on a specific invented word.

---

# 1. LR-A — river / basin adoption

## Starting facts

G1:

- predates LR-A;
- structures much of LR-A's basin;
- extends toward neighboring / upstream jurisdictions;
- reaches the Port interface;
- is not wholly controlled by LR-A.

LR-A nevertheless consolidates across much of its central basin.

## Strongest adoption sequence

~~~
old G1 hydronym
→ same root used for basin / lowlands in ordinary geography
→ tax / route / court records adopt geographic shorthand
→ one territorial authority consolidates across much of that area
→ outsiders use the basin name for the polity
→ river and polity share a common name without identical boundaries
~~~

**Mechanism: PASS.**

Important consequence:

A river-derived state name does not imply legal ownership of the whole river.

That ambiguity can itself produce political rhetoric with Port and upstream users.

# 2. NC-M — meeting-place / compact adoption

## Starting facts

NC-M grows from recurring coordination among:

- harbors;
- local territorial authorities;
- clan / kin institutions;
- shipowners;
- convoy / rescue / defense systems.

A simple city-equals-state adoption would flatten that history.

## Strongest adoption sequence

~~~
old principal mainland harbor name
→ recurring defense / rescue / diplomatic meetings held there
→ agreement or compact becomes known by the meeting place
→ coordination institutions become increasingly durable
→ mainland territorial state grows around those institutions
→ old compact label survives as common political name
~~~

**Mechanism: STRONG PASS.**

The word equivalent of **Compact** can become an institutional fossil:

- centralizers may treat it as merely inherited nomenclature;
- localists / islanders may cite it as evidence of the older bargain.

The actual harbor name and translated constitutional label remain open.

# 3. SH-A — ruling-seat metonym

## Starting facts

SH-A is a composite territorial polity built through a mix of:

- inheritance;
- marriage;
- protection;
- debt;
- negotiated incorporation;
- limited warfare.

Older jurisdictions retain local identities.

## Strongest adoption sequence

~~~
older ruling-seat settlement
→ one court based there expands authority
→ diplomats refer to "the court at [seat]"
→ records shorten the phrase when discussing central policy
→ outsiders increasingly use [seat] for the central polity
→ internal jurisdictions may still distinguish the court from their local identity
~~~

**Mechanism: PASS.**

This is a metonym, not evidence that the entire west began as one territory or one people.

The actual seat name remains open.

---

# 4. Anti-symmetry result

The three large actors can eventually receive common political names through different historical processes:

| V1 actor | Naming mechanism |
| --- | --- |
| SH-A | ruling-seat / court metonym |
| NC-M | inherited meeting-place / compact label |
| LR-A | river / basin geographic shorthand |

This is the important result.

The names do not merely need different sounds.

They should encode different political histories.

# 5. Current map usage

Continue to use:

- SH-A;
- NC-M;
- LR-A.

Do not substitute any of the failed lexical forms from the earlier tests.

The following grounded common-language names remain usable where already established:

- Last Quay;
- North Yard;
- South Yard;
- the Yards.

---

# 6. Promotion gate

A future lexical polity name should enter this page only after:

1. its underlying place / river / institution name has been independently derived from a real reusable linguistic layer;
2. the name passes the ordinary historical-name test;
3. same-cluster and neighboring-name QA does not expose artificial authorial patterning;
4. the adoption mechanism on this page still fits the polity's political history.

The adoption mechanism cannot rescue a weak lexical name.
