# Community Spiderweb Test — P1 Wave 1

## Status

**Challenge / promotion test — not setting canon.**

Source profiles:

- [Community Profiles — P1 Wave 1](Community-Profiles-P1-Wave-1.md);
- [Mobile Circuits — Working Profiles V1](Mobile-Circuits-Working-Profiles-V1.md).

Method:

- [Middle Worldbuilding](Middle-Worldbuilding.md);
- [Writing the Sequel](Writing-the-Sequel.md);
- [World Synthesis — E/I](World-Synthesis-EI.md).

## Test

For each P1 community, trace:

~~~text
livelihood
→ household
→ law / institution
→ guild / faith
→ food
→ architecture
→ leisure / memory
→ myth
→ current crisis
→ neighboring community
~~~

Then ask:

1. Does each connection follow from existing world evidence?
2. Does the community contain internal disagreement?
3. Does it exchange culture with neighbors?
4. Does history leave residue?
5. Would the community still make sense if the main plot never visited it?

Disposition:

- **P2-ready** — coherent enough for owner-page promotion at the structural/community-type level;
- **P1 hold** — useful but one or more important dependencies remain too abstract;
- **revise** — contradiction or theme-first construction detected.

# 1. SH-1 — industrial mine / civic district

## Spiderweb

~~~text
major extraction / workshops
→ mixed worker / craft / boarder households
→ mine / guild / civic / owner jurisdictions overlap
→ worker mutual-aid / education / guild institutions
→ cheap dense work food + imported staples
→ irregular industrial streets + polluted / safer districts
→ halls / music / reading / memorial culture
→ Knocking Below / Ore-Spoiler
→ strategic-priority production + labor conflict
→ food / labor / route dependence on Low Rivers + High Roads + Port
~~~

## Strong links

### Livelihood → household

Strong.

Existing Stone Hills culture already supports:

- workshop households;
- apprentices;
- older technical relatives;
- mixed income.

### Livelihood → architecture

Strong.

Industrial fire, waste, heavy transport, housing inequality already produce built form.

### Work → civic institutions

Strong after comparative research.

Worker halls / mutual-aid / training institutions arise naturally from:

- risk;
- injury;
- literacy;
- collective work.

### Work → myth

Very strong.

The Knocking Below now has a specific occupational reason to survive.

### Crisis → culture

Very strong.

Strategic allocation affects:

- wages;
- safety;
- household food;
- apprentices;
- guild loyalty.

## Weak links

### Faith

Still under-specified.

The Eternal Forge is an obvious temptation, but assigning it heavily simply because this is an industrial district would be theme-first worldbuilding.

Need later test:

- multiple faith institutions;
- secular worker organizations;
- which services each actually provides.

### Migration history

We know migrant labor exists as a useful mechanism, but not:

- from where;
- when;
- whether one migration wave mattered especially.

That matters for:

- language;
- neighborhood;
- food;
- songs.

## Disposition

**P1 HOLD.**

Strong community, but not yet P2-ready because migration / religious / neighborhood history are still too generic.

# 2. NC-1 — outer-island seasonal fishing community

## Spiderweb

~~~text
resident fishing / farming + seasonal fish run
→ extended resident households + seasonal boarders
→ harbor / fishery / rescue / lodging customs
→ kin + harbor + faith / mutual support overlap
→ preserved fish + hardy inland foods + imported grain
→ shore-following village + seasonal lodging + processing spaces
→ route songs / boat stories / local island memory
→ Great Mouth
→ fish decline + convoy politics
→ NC-3 harbor / mainland roadhead / Port
~~~

## Strong links

Nearly every link derives from:

- seasonal fishery;
- storm risk;
- island geography.

### Household

Strong.

Absence / loss / boarders emerge directly from fishing labor.

### Institution

Strong.

Rescue and fishery access are recurring coordination problems.

### Myth

Strong.

Great Mouth depends on rare maritime observation and local ecological knowledge.

### Neighbor relation

Strong.

NC-1 cannot function without:

- mainland trade;
- larger harbors;
- seasonal visitors.

## Weak links

### Faith

As with SH-1, no need to assign one dominant tradition.

This is an open detail rather than structural weakness.

### Exact island ecology

Needs a site later:

- fresh water;
- harbor depth;
- pasture / croft-like land;
- fish run.

But the community type does not depend on one exact island yet.

## Disposition

**P2-READY.**

Promote as a valid North Coast community type, not as one named island culture.

# 3. NC-3 — major compact harbor

## Spiderweb

~~~text
major fish / cargo harbor
→ merchant / crew / warehouse / seasonal-worker households
→ private quay rights + harbor-wide coordination
→ merchant institutions + civic harbor office + guilds
→ local fish + imported foods + class-differentiated consumption
→ warehouse / quay / repair / lodging districts
→ sailor culture + merchant public culture + record culture
→ Great Mouth transformed / standardized
→ convoy / piracy constitutional dispute
→ NC-1 islands + NC-R + Port + inland districts
~~~

## Strong links

### Economy → institution

Very strong.

Fragmented property plus shared harbor problems naturally produce harbor-wide authority.

### Class differentiation

Strong.

Merchant / crew / seasonal worker interests are materially distinct.

### Myth transmission

Strong.

NC-3 acts as an intermediate transformation hub between island oral traditions and Port.

## Weak links

### Site specificity

The harbor is still an abstract "major harbor."

Need later:

- exact sheltered geometry;
- river / freshwater;
- inland-road relation;
- relation to NC-M central authority.

### Neighborhood history

We know layers should exist but not which came first at one concrete site.

Without that, the community is a good **type** but weak as a specific place.

## Disposition

**P1 HOLD as a specific community; P2-ready as a harbor type.**

Do not promote a named major harbor until map / site history selects one.

# 4. LR-1 — cooperative irrigation village

## Spiderweb

~~~text
shared water dependency
→ farm households with uneven land / labor
→ water-user association + obligations
→ village / cooperative / state overlap
→ grain / pulses / vegetables / dairy / stored food
→ fields / channels / maintenance paths / mixed compounds
→ maintenance-day social life + seasonal visiting
→ Marsh Lure on forgotten channels
→ abundance / debt despite competent production
→ river market + estates + neighboring villages
~~~

## Strong links

### Water → institution

Very strong.

This is one of the most causally grounded communities.

### Rights → obligations

Strong.

Maintenance labor prevents abstract "communal water" worldbuilding.

### Crisis

Very strong.

The community can be well organized locally and still be crushed by:

- credit;
- storage;
- market price.

That distinguishes local competence from systemic power.

## Weak links

### Architecture

Current architecture pass focuses mill / market town rather than an irrigation village.

Need a later small pass on:

- farm compounds;
- channels;
- shared structures;
- flood / drainage interface.

Not a blocker to the community type.

## Disposition

**P2-READY.**

# 5. LR-4 — floodplain settlement

## Spiderweb

~~~text
seasonally moving water
→ households divide work among crops / fish / animals / boats
→ flood-warning / refuge / access institutions
→ local water users + LR-A emergency systems
→ flood-adapted food production
→ raised / movable / sacrificial structures
→ seasonal route knowledge / flood-memory culture
→ Marsh Lure
→ debt / drainage / storage pressure
→ LR-1 villages + river markets + Old Cities water migrants
~~~

## Strong links

### Ecology → daily life

Very strong.

The entire community changes with water stage.

### Ecology → myth

Exceptional.

Marsh Lure belongs here because even experts face:

- shifting channels;
- altered distances;
- night / fog uncertainty.

### Ecology → politics

Strong.

Flood-control projects create winners / losers.

## Weak links

### Actual local hydrology

This is the main blocker.

Need to know whether the chosen settlement is:

- delta-like;
- river bend;
- backwater;
- seasonal marsh;
- tributary floodplain.

Different hydrology changes:

- crops;
- boats;
- structures;
- institutions.

### Technology / flora

Floating cultivation is only a comparator, not yet a local practice.

Do not canonize it before material/ecology review.

## Disposition

**P1 HOLD.**

The type is strong; a site / hydrology decision is needed before promotion.

# 6. LW-1 — western edge compact community

## Spiderweb

~~~text
forest products + market / road demand
→ mixed local / migrant / wage households
→ town + compact + use-right + specialist jurisdictions overlap
→ compact / community / guild / warden institutions
→ purchased grain + river / forest foods
→ town / landing + worker camps + roads / bridges
→ market culture + rights rhetoric + mixed worker life
→ Forest Owner as contested political story
→ road / concession dispute
→ Stone Hills / Low Rivers migrants + LW-2 users
~~~

## Strong links

### Economy → political form

Very strong.

Outside contracts need a shared negotiator.

That creates compact authority.

### Political form → conflict

Very strong.

The compact can approve something it does not possess the local right to grant.

This is not arbitrary worldbuilding; it is the community's defining institutional problem.

### Myth → politics

Very strong.

Different versions of Forest Owner map directly onto:

- property;
- obligation;
- extraction.

### Story

Exceptional.

This is now a credible home for Wurdren's Longwood dispute.

## Weak links

### Migrant composition

We know migrant labor matters, but not source regions / generations.

### Specific forest economy

Need later decision on relative importance of:

- timber;
- charcoal;
- other forest products;
- agriculture;
- river trade.

## Disposition

**P2-READY at structural level.**

Open economic proportions should remain local variables, not block the community type.

# 7. LW-2 — interior use-right community

## Spiderweb

~~~text

→ local community + mandate-limited delegates + specialist overlap
→ mixed cultivation / purchased staples / seasonal forest foods
→ dispersed settlement / paths / work areas rather than one "forest village" form
→ boundary / use memory + local narratives
→ Forest Owner

~~~

## Strong links

### Rights → society

Exceptional.

The community's politics arise from actual overlapping use.

### Rights → myth

Exceptional.

Forest Owner becomes a story about:

- assuming one permission implies another;
- ignoring other users.

### Internal politics

Strong after comparative research.

The question:

> who counts as a legitimate user?

prevents romantic communalism.

## Weak links

### Settlement / architecture

Current architecture research is river-town focused.

LW-2 may be:

- clustered;
- dispersed;
- seasonal;

depending on ecology / use.

Do not invent one interior Longwood architectural type yet.

## Disposition

**P2-READY at institutional/community-type level.**

Site form remains open by design.

# 15. Emergent cross-connections

## E/I candidate A — myth preserves jurisdiction

The strongest myths are increasingly tied to **who has the right to act**:

- Forest Owner → use rights;
- Charter Beast → water / legal rights;
- Estuary Captive → personhood / custody;
- Knocking Below → worker authority over unsafe work.

This suggests:

> **mythic creatures in 10Kings may often preserve contested jurisdiction more strongly than cosmology.**

That is distinctive enough to retain as an E/I candidate.

## E/I candidate B — mobile people are folklore infrastructure

M-1 / M-2 / M-3 show different myth-carrier roles.

This suggests:

> **folklore transmission should be mapped through occupations and circuits, not just geographic adjacency.**

Already consistent with Phase 7 cultural transmission.

## E/I candidate C — practical knowledge and supernatural belief are not opposites

Across:

- island fishers;
- floodplain experts;
- miners;
- herders;
- forest users

the people with the most practical expertise may also preserve the strongest creature traditions.

Therefore avoid:

> educated / competent = skeptic  
> ignorant / rural = believer

A professional can use natural explanation and folklore simultaneously.
