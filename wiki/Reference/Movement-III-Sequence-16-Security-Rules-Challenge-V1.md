- temporary practices become recurring rules because they reduce real risk;

- local / pastoral exceptions force correction;

---

# 1. Stretch the timeline

V1 formalizes the rule after nine days.

That is too quick for:

- multiple roadheads;
- several seals;
- contribution arguments;
- local exceptions.

Better:

> temporary roadhead rules operate for several weeks, are revised repeatedly, and only then become a compact-recognized common sheet.

This still feels fast under crisis pressure.

It no longer feels instantaneous.

---

# 2. Show aggregation from existing practices

The compact should not invent the whole system at once.

It should standardize pieces already being used separately:

- guarded windows from one roadhead;
- transition verification from another;
- route-warning form from another;
- contribution schedule adapted from escort practice.

That reinforces:

> interoperability rather than centralization.

---

# 3. Remove technology-specific dangerous cargo

The "restricted blasting material" example may over-specify current technical / legal canon.

Replace with something already supported:

- cargo weight / class materially misdeclared;
- forged route notice;
- unrecognized guard / carrier credentials;
- unsafe bridge-capacity mismatch.

---

# 4. Do not create a reserve-escort roster yet

Recognized escort providers are enough for Sequence 16.

The roadhead can know:

- who is licensed / recognized;
- which providers are available for upcoming departures.

That already tells the system:

- armed capacity;
- availability;
- timing.

A true reserve roster can appear later as readiness fear increases.
