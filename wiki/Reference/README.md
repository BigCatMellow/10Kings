## Legacy reconciliation backlog

Valuable, setting-specific legacy material that has never been promoted or declined, found by the [World Review](World-Review-2026-11.md). Each item is consistent with current canon unless noted. Nothing here is canon; it is listed so it isn't lost. When an item is reconciled, record it in the [Source Register](Source-Register.md) and strike it here.

The rule for reconciling them: **promote the line and the mechanism, never only the category.** Earlier passes turned specific lines into generic lists ("witnessed by whoever's sober" became "which ritual occurs first"); the legacy notes now hold most of the world's spoken texture.
