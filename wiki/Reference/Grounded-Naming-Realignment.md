# Grounded Naming Realignment

## Status

**Working naming migration / reference.**

This page records the September 2026 realignment toward grounded, ordinary place names.

The governing rule is [Naming](../Culture/Naming.md).

## Core decision

Names should not sound important merely because the place is important.

A settlement usually receives a name when ordinary people need to refer to:

- a field;
- a ford;
- a river;
- a spring;
- a hill;
- a bridge;
- a market;
- a farm;
- a family holding;
- a church / shrine;
- a mill;
- a fort;
- a gate;
- a harbor;
- an older settlement.

The name can later become politically important without becoming grander.

**Springfield is the model, not Ch'tevial.**

Opaque or non-English-looking names are not forbidden, but they must emerge from an actual linguistic history. Until that history exists, inventing exotic syllables is worse than using a plain translated name.

# Macro-region realignment

These broad cultural-geographic labels are now being replaced with deliberately ordinary common-language names.

| Previous label | New working common label | Why |
| --- | --- | --- |
| Ironcrest | **Western Uplands** | literal geography; avoids turning mining into the region's name |
| Northwind | **North Country** | ordinary directional regional name; broad enough for coast, islands, and inland districts |
| Greenvale | **River Country** | major rivers, farms, mills, market towns and floodplains are structural rather than decorative |
| Highridge / Highridge Plateau | **High Country** | ordinary description for elevated route country; not a prestige title |
| Deepwood | **Forest Country** | literal broad geographic label; avoids mystical / fantasy branding |
| Sunplains | **South Country** | ordinary directional regional label broad enough for plains, river basins, coasts and city-states |
| The Spine | **The Spine** | retained; simple geographic metaphor that already feels inherited |
| The Underpass | **The Underpass** | retained; ordinary functional shorthand that already works as a proper name |
| Port | **Port** | retained because its almost boring shorthand is plausible for an internationally familiar harbor city |

## Important

These are **common-language labels**, not necessarily local endonyms.

A person may say:

- “the Western Uplands” in a treaty;
- “the uplands” in ordinary speech;
- a much older valley name locally.

The common label does not erase local naming history.

---

# Why the old macro names changed

Several previous labels shared the same authorial structure:

```text
region's defining theme
+ evocative landscape word
= fantasy region name
```

Examples:

- Iron + crest;
- Green + vale;
- Deep + wood;
- Sun + plains;
- High + ridge;
- North + wind.

They were readable, but together they made the world feel **designed from above**.

The new labels are intentionally less branded.

Real cultural depth should come from:

- towns;
- river names;
- family names;
- neighborhood names;
- local speech;
- institutions;
- history;

not from making every macro-region name carry its theme.

- Summithold;

- Thunderstair;
- Icefang;
- Deepwell Sanctum;
- similar theme-first compounds in the legacy notes.

## New rule for replacing them

Do not replace them with another invented fantasy list.

A replacement should wait until we know at least one concrete naming cause.

Examples:

### Route town
Possible sources:
- North Gate;
- East Gate;
- Upper Pass;
- Three Wells;
- New Market;
- Bridge End;
- Toll Cross;
- Miller's Gap;
- a family surname.

### Industrial town
Possible sources:
- river name;
- mine owner's family;
- old village;
- bridge;
- ford;
- mill;
- market;
- later district nickname.

The industrial identity does **not** require a name containing iron, forge, smoke, black, ember, or steel.

### Agricultural town
Possible sources:
- river;
- field;
- mill;
- ford;
- church;
- estate family;
- market;
- soil / water description.

It does not require green, harvest, orchard, seed, or hearth.

### Forest town
Possible sources:
- river bend;
- crossing;
- family;
- species actually used in local naming;
- old clearing;
- ferry;
- mill;
- shrine.

It does not require root, moss, leaf, gloom, shadow, or whisper.

### Southern city-state
Possible sources:
- founder / dynasty;
- well;
- spring;
- canal;
- gate;
- river;
- hill;
- market;
- older settlement.

Do not invent pseudo-Persian / pseudo-Arabic / pseudo-Latin syllables merely to signal climate or culture.

# Opaque names

A real world contains opaque names because languages change.

But the setting should **earn** them.

An opaque name can enter canon when at least one of these exists:

1. an established language or older substrate;
2. a known historical personal / family name;
3. a documented borrowing from another language;
4. a convincing sound change from an older transparent form;
5. an inherited old name whose meaning is intentionally unknown but whose linguistic context exists.

Without that support, an opaque invented word is just authorial noise.

This reverses the earlier assumption that a name such as **Zalhar** was strong merely because it looked old and opaque. It may still survive later, but only if an actual language history produces or supports it.

---

# Personal names

The same grounded rule applies to people.

Do not generate “fantasy names” by aesthetic region.

Personal names should come from:

- actual naming systems;
- family / kinship;
- religion;
- saints / exemplars / ancestors;
- ordinary historical given-name pools;
- occupational or place bynames;
- patronymics / matronymics;
- migration / transliteration.

A plain name with a social history is better than a unique invented name with none.

# Repository transition

For now:

- active wiki prose should use the new macro labels;
- existing region / place **filenames may retain legacy slugs** so links do not need to be broken during the naming migration;
- legacy notes remain unchanged;
- older specific polity names remain usable in reference pages only when discussing their legacy evidence;
- new culture / food work should use the new macro labels.

Once the new naming system is stable, filenames can be migrated separately if useful.

# Success test

A grounded name should usually allow a sentence like:

> “They call it Millford because there was a mill beside the ford.”

or:

> “The treaty calls the district North Country because it was simply the northern country from the old negotiating centers.”

It does **not** need:

> “The ancient word Ch'tevial means the Crown of Eternal Dawn in the lost tongue of…”

unless that lost language and history already exist for reasons beyond rescuing the name.

The setting should be comfortable with boring names.

That is how important places often begin.


## Second-pass macro names

The first grounded correction intentionally overshot toward generic labels such as **River Country** and **Forest Country**.

Those labels solved the fantasy-branding problem but read too much like temporary map categories.

The second pass keeps ordinary naming logic while allowing each macro-region a more specific historical shorthand.

### Working set

| First grounded label | Second-pass working name | Naming logic |
| --- | --- | --- |
| Western Uplands | **the Stone Hills** | ordinary geographic shorthand for the old western upland core; stone/hill country predates any single mining polity |
| North Country | **the North Coast** | simple external/common name rooted in the maritime core; inland and diaspora communities can still belong culturally |
| River Country | **the Low Rivers** | common description of the broad lower river systems and settled lowlands around them |
| High Country | **the High Roads** | historical route-country name built from the roads, passes and caravan network rather than from altitude alone |
| Forest Country | **the Longwood** | common name for the great historical forest core; does not imply all forests belong to it |
| South Country | **the Old Cities** | cultural-historical shorthand for the old city-state / irrigation heartland rather than a climate label |
| The Spine | **The Spine** | retained; plain geographic map term works |
| The Underpass | **the Underpass** | retained; ordinary common shorthand works |
| Port | **Port** | retained; deliberately plain international shorthand works |

### Why these work better

They are still ordinary.

None require:
- a fabricated ancient language;
- apostrophes;
- prestige syllables;
- a fantasy suffix;
- a symbolic national myth.

But they have different histories and shapes.

They also work as cultural labels without becoming ethnic borders:

- a **Stone Hills** family can live in Port;
- a **North Coast** clan can settle another coastline;
- a **Low Rivers** milling community can establish itself beside a distant river;
- **High Roads** merchant families can maintain houses far from the plateau;
- a **Longwood** community can exist in another large forest;
- **Old Cities** merchant / civic traditions can survive in distant colonies or neighborhoods.

The name identifies a historical cultural core, not exclusive possession of a biome or territory.

### Still provisional

These names are stronger than the first generic correction but remain working names.

If later local history yields a better ordinary name—a river name, family name, old road term, or historically attested exonym—that can still replace them.
