# Legacy Source-Level V2 Ledger

## Status

**Active provenance / review-control ledger — not setting canon.**

This ledger records the second-pass review status of the **220 original Markdown source notes** preserved in the consolidated legacy package.

It exists to distinguish:

- source **screened** for salvage;
- source **deep reviewed** because it showed high forward value;
- source merely present in the archive.

Current wiki owner pages always outrank this ledger.

See [Legacy Master Salvage Pass — V2](Legacy-Master-Salvage-Pass-V2.md).

## Status meanings

- **SCREENED V2** — inspected at source-section level for mechanisms, institutions, ordinary-life detail, logistics, conflict, and story value.
- **DEEP REVIEWED V2** — received a focused semantic review during the structural reconciliation and/or the current V2 salvage pass.
- **STUB / EMPTY** — source contains little or no substantive setting material.

The ledger does **not** imply that every useful sentence has already been promoted. Deep-review and promotion remain iterative.
