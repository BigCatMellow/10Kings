# Legacy Source-Level V2 Inventory

## Status

**Active audit / retrieval control — not setting canon.**

This inventory records the source-level screen of the original legacy archive during the V2 salvage pass.

It exists because a volume-level label such as **RECONCILED** was too coarse: useful mechanisms could remain buried inside individual source files.

All **220 original source entries** in the 14 consolidated volumes are accounted for below.

## Meaning of columns

- **Screen:** every row marked `SCREENED V2` was included in the source-section inventory and mechanism scan.
- **Priority:** retrieval priority for deeper future salvage, not a canon rating.
  - **HIGH** — dense current-system / conflict / institutional material; should be mined before inventing in that area.
  - **MEDIUM** — contains potentially useful local mechanisms or examples.
  - **LOW** — mostly duplicate, generic, obsolete-wrapper, or narrow flavor material; still preserved.
- **Reason:** why the source was routed at that priority.

A source can contain both useful and rejected material. Current owners always outrank this inventory.

Related: [Legacy Master Salvage Pass — V2](Legacy-Master-Salvage-Pass-V2.md).
