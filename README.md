# 10Kings

Worldbuilding repository for the **Two Sons** setting.

The repository is organized as a wiki-style knowledge base under `wiki/`. The goal is to keep the setting coherent while preserving uncertainty where ideas are still provisional.

## Canon status

Pages distinguish between:

- **Established** — repeatedly used or explicitly retained in discussion.
- **Working canon** — current best version, but still open to refinement.
- **Provisional** — useful idea that should not silently become fixed canon.

This matters because the setting has grown through iterative brainstorming and several earlier ideas conflict or have been superseded.

## Wiki note

The connected GitHub tools can edit repository files but do not expose GitHub's separate Wiki repository. The `wiki/` folder is therefore the canonical source for the wiki material and is structured so it can be copied into GitHub Wiki pages later without reorganization.
